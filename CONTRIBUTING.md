# Contribuir a Google Customer Reviews Shopify

¡Gracias por tu interés en contribuir!

## 🐛 Reportar Bugs

Si encuentras un error:

1. Verifica que no esté reportado en [Issues](https://github.com/libradamarrero176-gif/google-customer-reviews-shopify/issues)
2. Incluye:
   - Descripción clara del problema
   - Pasos para reproducirlo
   - Captura de consola (DevTools)
   - Tu Merchant ID (parcialmente oculto)

## 💡 Sugerir Mejoras

- Abre un [Discussion](https://github.com/libradamarrero176-gif/google-customer-reviews-shopify/discussions)
- Describe la mejora que propones
- Explica el beneficio

## 🔧 Pull Requests

1. Fork el repositorio
2. Crea una rama: `git checkout -b feature/mi-mejora`
3. Haz commits: `git commit -am 'Agrega mi mejora'`
4. Push: `git push origin feature/mi-mejora`
5. Abre un Pull Request
